# Python Discount Calculator

This repository contains a Python program that calculates the final price of an item after applying a discount.

## Description

The program defines a function `calculate_discount(price, discount_percent)` which applies a discount only if the discount percentage is 20% or higher. If the discount is less than 20%, the original price is returned.

The user is prompted to enter the original price and the discount percentage. The program then prints the final price after applying the discount or the original price if no discount was applied.

## Usage

Run the script:

python discount_calculator.py
